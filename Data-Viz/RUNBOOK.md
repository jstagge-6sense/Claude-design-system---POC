# 6DS build runbook

Order: **1 → 2 → 4 → 8 → 3.** Dark mode and the three sizes (old step 5) are part of the core package, built in step 2. The basic (non-6DS) React package is not built. GitHub publishing (old step 6) and the Figma page rebuild (old step 7) are not part of this kit.

Before you start, run `node scripts/first-run.mjs`. It shows the saved GitHub repo and Figma file and asks whether to update them (see `config/targets.json`).

All commands run in `package/`, or run `scripts/build-all.sh` for the whole sequence.

## 1. Components
- 51 components in `package/src/components/<Name>/` (code, CSS Module, stories, tests, Code Connect stub).
- Source rules: `package/docs/source/*.md`, starting with `Resources.md`, then `COMPONENT_AUTHORING.md`.
- Add a component: `npm run new:component`. Check all: `npm run check:components`.
- **Done when:** the check passes with 51/51 complete.

## 2. Tokens (with dark mode and sizes)
- Three layers in `package/tokens/`: `primitive`, `semantic`, `component`.
- Modes (step 5, built in here): `tokens/modes/dark.json` and `tokens/modes/density.json` (Compact 0.75x, Default, Spacious 1.25x; spacing and control height only).
- Build: `npm run build:tokens` (also emits `:root[data-theme="dark"]` and `:root[data-density="compact|spacious"]`).
- Lint: `npm run lint:tokens`.
- **Done when:** lint is clean. Dark values are drafts (32 contrast pairs pass AA) and need design sign-off.

## 4. Trim the tokens
- `npm run build:lean` removes component tokens that only point at one semantic token, and rewrites component CSS to use the semantic token.
- 1,567 → 884 tokens (131 primitive, 109 semantic, 644 component).
- **Done when:** lint still passes and nothing looks different.

## 8. The 6DS package
- Name `@6si/components`. Vite library build, ESM and CJS, `"use client"` banner, one `styles.css`, subpath exports.
- Material UI bridge (`src/mui`, theme generated from tokens: `npm run build:mui-theme`), react-hook-form bindings (`src/hook-form`), working examples in `examples/` (react-hook-form, React Query, MUI).
- Redux-Saga notes and adoption steps: `docs/ADOPTION.md`.
- Build: `npm run build && npm run typecheck && npm test`.
- **Done when:** `dist/` has `index`, `mui`, `hook-form` in both formats plus `styles.css`. Not yet run end to end; expect small fixes on first install.

## 3. Preview (last)
- `npm run preview` writes one offline file, `preview/design-system-preview.html`, with the token editor, Light/Dark and Compact/Default/Spacious switches, and lean token counts.
- Open it by double-clicking. Edit tokens live, then apply with `npm run tokens:apply`.

## 9. Charts (added)
- `package/src/charts/`: seven Highcharts-based DBA charts (Area spline, Line, Bar single, Bar stacked/grouped, Donut, Funnel, Pareto) on one shared theme, palette and formatter set. See `package/src/charts/README.md`.
- Colors are 6DS tokens only (generated by `npm run gen:chart-palette`). Check: `npm run verify:charts` (palette equals tokens, 3:1 contrast, no raw colors).
- Needs `highcharts` 12.2+ (optional peer dependency). Subpath export `@6si/components/charts`.
- **Done when:** `npm install`, `npm run typecheck`, `npm test` and Storybook (`Charts/DBA charts`) pass. Not yet run against a live Highcharts install.
