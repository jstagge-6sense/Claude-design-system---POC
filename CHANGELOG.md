# Changelog

## 0.1.0

First packaged release. 62 items built here (51 components, 8 charts, Icon, Portal, Visually Hidden), three-layer tokens (primitive, semantic, component), light and dark modes, compact and spacious density.

- Table: row actions (up to 3 buttons or one menu), built-in search, filters and sorting.
- Input and field components: required marker in red in front of the label, optional marker after it, help icon with popover, info, success and warning messages.
- Package: `exports` map for the library, `styles.css` and the token files.
